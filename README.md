# Conejo Valley Counseling Marketing Preview

This project is a colorful, visual marketing preview designed to present the counseling brand in a warm, polished, and client-friendly way. It is meant to feel inviting, modern, and emotionally engaging while highlighting the therapist’s expertise and the practice’s calming atmosphere.

## Visual direction

This is the part that makes the site feel market-ready and attractive:
- warm beige and soft neutral backgrounds
- strong deep blue primary tones for trust and professionalism
- gold accent colors for warmth and emotional appeal
- clean spacing and modern typography for a premium feel
- calming wellness aesthetic that supports therapy positioning

The colors are defined in [app/globals.css](app/globals.css) and applied across the homepage and therapist page.

## Purpose

This preview helps a client evaluate:
- the overall visual direction and mood
- the brand personality and tone
- the therapist’s positioning and credibility
- the value proposition for anxiety, trauma, and burnout support
- the clarity of the consultation call-to-action

## What makes it visually strong

- rich, cohesive color palette
- calming but vibrant wellness aesthetic
- clear service highlights and benefits
- strong therapist branding and messaging
- responsive layout for client presentation on desktop and mobile

## How to open the preview

### 1) Open the project folder

```bash
cd d:\conejo-valley-counseling
```

### 2) Install dependencies

```bash
npm install
```

### 3) Start the local preview

```bash
npm run dev
```

### 4) Open the site in the browser

```text
http://localhost:3000
```

This gives you a live visual presentation that can be shown to a client for feedback and approval.

## Pages to review with the client

### Homepage
- overall brand impression
- calming visual identity
- office atmosphere and trust-building messaging

### Therapist page
- expertise and therapist positioning
- services and treatment specialties
- FAQs and conversion-focused CTA

## Client presentation flow

1. Launch the site locally
2. Show the homepage to establish the brand tone and aesthetic
3. Move to the therapist page to talk through expertise and services
4. Highlight the consultation button and conversion path
5. Gather feedback on visual direction, clarity, and messaging
