# Conejo Valley Family Counseling — Next.js

This project packages the supplied site inside a JavaScript-only Next.js application with Tailwind CSS available for future enhancements. The original downloaded website files remain unchanged under `public/site`, preserving the existing layout, fonts, styles, images, and interactions.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```
