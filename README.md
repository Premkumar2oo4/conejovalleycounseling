# Conejo Valley Counseling Marketing Preview

This project is a marketing preview for the counseling practice. It is designed to present the brand, therapist profile, and overall feel to clients in a clean, polished way during review.

## Purpose

This site is meant to help a client evaluate:
- the overall brand direction
- the therapist’s positioning and credibility
- the tone and feel of the practice
- the key services and value proposition
- the conversion flow to inquire or book a consultation

## What is included

- Homepage overview for the practice
- Therapist profile page for Dr. Maya Reynolds
- Calm, wellness-focused visual direction
- Strong service messaging and consultation CTA
- Responsive presentation for review on desktop and mobile

## How to open the marketing preview

### 1) Open the project folder

```bash
cd d:\conejo-valley-counseling
```

### 2) Install dependencies

```bash
npm install
```

### 3) Run the preview locally

```bash
npm run dev
```

### 4) View the site in the browser

```text
http://localhost:3000
```

This gives you a live marketing preview that can be shown to a client for feedback.

## Pages to review with the client

### Homepage
- Main brand presentation
- Practice positioning
- Office atmosphere and trust-building messaging

### Dr. Maya Reynolds page
- Therapist expertise and bio
- Services and treatment focus
- FAQs and consultation CTA

## Marketing review workflow

1. Launch the preview locally
2. Open the homepage and walk through the brand impression
3. Review the therapist page for messaging and credibility
4. Present the CTA flow and consultation path
5. Gather feedback on tone, conversion clarity, and messaging

## Content and design files

- `app/page.js` — homepage marketing content
- `app/drmayareynolds/page.js` — therapist profile and service messaging
- `app/globals.css` — overall visual theme and color palette

## Notes

- This is a marketing and presentation preview, not a deployment guide.
- It is intended to help clients review the concept and approve the direction before final launch work.
